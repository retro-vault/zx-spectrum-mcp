# Local ROM images

This directory is the conventional local location for ROM images used by
the emulator:

- `48.rom` — 16K ZX Spectrum 48K ROM, loaded with `--rom`.
- `if1-2.rom` — 8K ZX Interface 1 shadow ROM, loaded with
  `--interface1-rom`.

The binary ROMs are intentionally matched by the repository's `*.rom`
ignore rule. Their copyright and redistribution terms are separate from the
GPL-covered emulator source.
